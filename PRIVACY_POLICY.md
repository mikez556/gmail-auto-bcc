# Gmail Auto BCC — Privacy Policy

Last updated: 18 November 2026

Gmail Auto BCC helps the user add a chosen blind-carbon-copy (Bcc) recipient when composing emails in Gmail's website.

## Information handled
The extension stores the user-entered Bcc email address and the on/off and reply/forward preferences using Chrome's `storage.sync` mechanism. When Chrome Sync is enabled, Google Chrome may synchronize these settings across the user's signed-in compatible browser profiles. Chrome extension storage is not a secure vault; do not enter secret credentials.

The extension examines limited Gmail webpage structure locally to find the compose window, Bcc controls, and current recipient elements. It does not copy, store, or transmit email bodies, attachments, or recipient lists to the developer. It inserts the user's saved Bcc address into the Gmail compose interface; Gmail subsequently handles emails as normal when the user sends them.

## Sharing and transfers
The developer does not operate a server receiving extension data and does not sell or share the user's information with advertisers. Google Chrome may process synchronized settings as part of its Chrome Sync service. Gmail handles email content according to the user's Google account settings and Google's policies.

## Storage and control
Users can change or disable the Bcc feature in the extension popup. Uninstalling the extension removes its normal Chrome extension storage from that browser; synced copies may be retained or removed according to Chrome Sync behavior.

## Security and limited use
The extension runs only on `mail.google.com`, requests only the Chrome `storage` permission, and executes no remotely hosted code. The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
